As part of my final project for the UX/UI Design course (Coderhouse), I decided to develop a functional application prototype that would help us in the future to facilitate recipe access for entrepreneurs participating in the assistance program.

Throughout the project, I worked through various UX/UI stages, including:

🔹 Problem research and definition
🔹 Desk research and benchmarking
🔹 User persona definition, empathy map, and point of view (POV)
🔹 MVP definition and storytelling
🔹 Information architecture and user flows
🔹 Progressive wireframe design
🔹 Functional prototyping and usability testing
🔹 Heuristic evaluation and accessibility

*The development of the work is summarized in the attached pdf file "ReporteUX+Landoni.pdf".*
